# Instalación del Sistema Calendario Completo

## 🚀 Instalación Rápida (5 minutos)

### Método Automático (Recomendado)
1. **Sube todos los archivos** a tu servidor web
2. **Ve al navegador:** `http://tu-servidor/calendario/install/`
3. **Sigue los 5 pasos** del instalador automático
4. **¡Listo!** Sistema completamente funcional

### Método Manual
1. **Copia** `install/config-sample.php` → `config.php`
2. **Edita** `config.php` con tus configuraciones de BD
3. **Ejecuta** `install/database.sql` en tu MySQL
4. **Accede** a `calendario.php` para usar el sistema

## 📋 Requisitos del Sistema

### Servidor
- **PHP 7.4+** con extensiones: `pdo`, `pdo_mysql`, `mysqli`, `json`, `mbstring`, `curl`, `gd`
- **MySQL 5.7+** o **MariaDB 10.0+**
- **Apache/Nginx** con soporte para `.htaccess`

### Permisos
- **Escritura** en directorios: `logs/`, `cache/`, `admin/`, `api/`
- **Ejecución** de scripts PHP

## 🚀 Uso Después de la Instalación

### Acceder al Sistema
- **Calendario principal:** `http://tu-servidor/calendario/calendario.php`
- **Panel admin:** `http://tu-servidor/calendario/admin/api_keys_admin.php`
- **API pública:** `http://tu-servidor/calendario/api/public_eventos.php`

### Primeros Pasos
1. **Inicia sesión** como administrador con las credenciales del instalador
2. **Crea tu primer evento** desde el panel principal
3. **Genera API keys** desde el panel de administración
4. **Configura categorías** y personaliza el sistema

## 🔧 API Endpoints

### GET /api/public_eventos.php?action=listar
Lista eventos públicos con filtros opcionales.

**Parámetros:**
- `fecha_desde`, `fecha_hasta`: Rango de fechas
- `tipo`: Tipo de evento
- `categoria`: Nombre de categoría
- `q`: Búsqueda por texto
- `limite`, `pagina`: Paginación

### GET /api/public_eventos.php?action=detalle&id={ID}
Detalles completos de un evento específico.

### GET /api/public_eventos.php?action=calendario
Eventos formateados para calendarios externos (FullCalendar).

### GET /api/public_eventos.php?action=categorias
Lista de categorías disponibles.

### GET /api/public_eventos.php?action=empresas
Lista de empresas organizadoras.

## 📞 Cliente API Incluido

También se incluye un **cliente PHP completo** en `cliente/` para consumir la API desde otros servidores:

```php
require_once 'cliente/CalendarioAPI.php';

 = new CalendarioAPI();
 = (['limite' => 10]);
```

## 🆘 Solución de Problemas

### Error de conexión a BD
- Verifica las credenciales en `config.php`
- Asegúrate de que la BD y tablas existen

### Permisos de escritura
```bash
chmod 755 logs/ cache/ admin/ api/
```

### API no responde
- Verifica que la API esté habilitada en configuración
- Revisa logs en `logs/api_client.log`
